# 更新记录

按版本从新到旧排列。0.3.0～0.4.5 的说明原文迁自旧版 README；对应 APK 见 [Releases](https://github.com/yejiu0210/one-tap-checkin-android/releases)，验证证据见 [verification.md](verification.md)。

## 0.4.5（2026-10-18）贴吧签到自检

0.4.5 增加贴吧普通签到自检。提交返回成功码或重复签到码都不足以单独完成任务；只有身份匹配的服务端状态明确显示该吧今日已签才输出完成。自检不可用时，不用本地旧成功记录代替。只读状态入口最多返回200个吧，缺失目标会保留待确认；需要有效的官方网页会话，必要时重新网页登录更新凭证。

同版简化点赞完成判定：确认点赞生效后即完成，不单独查询经验，不再显示「经验待官方确认」；旧记录中的同类提示也会隐藏。

## 0.4.4（2026-10-17）移除小黑盒

0.4.4 已按用户要求移除小黑盒功能。覆盖安装后，旧小黑盒账号、凭证、历史与操作进度会从本地加密状态中清理；其他四个平台的账号、任务、记录及外观设置保留。

同版处理贴吧主 `forum_id=0` 的候选：不在该帖写入，仅在零写入阶段跳过候选，详见 [evidence/tieba-zero-forum-0.4.4.md](evidence/tieba-zero-forum-0.4.4.md)。

## 0.4.3（2026-10-17）贴吧选帖修复

贴吧保留 0.4.3 的处理：遇到已核实的“贴子可能已被删除”等不可用详情响应，继续检查当前吧最多 10 个不同候选，找到有效帖子后执行并确认点赞；已发送操作后状态不明不换帖。只有尚未发送任何操作且明确遇到其他帖子 / 吧 ID 或已核实不可用响应的旧候选，允许一次同吧恢复。真实账号修复效果仍待本人复测。

## 0.4.2（2026-10-17）取消全部随机一赞

修复登录会话导入与有界的同吧候选恢复；新增「取消全部随机一赞」。

## 0.4.1（2026-10-17）贴吧点赞协议修复

贴吧对照原 Android 客户端修正点赞对象参数，处理0.4.0用户反馈的 `300000` 相关不兼容。旧任务如果已到请求次数上限，只有同账号、同吧、同日最近明确记录该错误且当前帖子状态可确认时，允许一次同帖协议修复；不清空进度或换帖。安装后可点「仅重试失败 / 待确认项」，再到官方核对点赞；修复效果仍待真实账号验收。

## 0.4.0（2026-10-17）夜间模式与每吧点赞

新增夜间模式、按吧可选的每日随机点赞（以及后来在 0.4.4 移除的小黑盒签到）。

## 0.3.0（2026-10-17）登录白屏修复与黑胶乐签

0.3.0 修正官方移动域名 / 子框架导航兼容、固定登录原生工具栏，并改用鹰角账号中心 SDK。2026-10-17 用户在此前反馈白屏的手机（Redmi K90 Ultra / Android 17）回复「测试完成，都可以正常签到」。这是用户报告的真机验收，开发侧没有接触账号或独立操作设备，也没有获得每角色、跨日和经验到账的详细证据。部分官网仍可能要求本人验证。登录边界见 [integration-web-login.md](integration-web-login.md)。

网易云音乐改为用户明确确认的「黑胶乐签」，移除普通 Android dailyTask 签到，见 [integration-netease-vip.md](integration-netease-vip.md)。

## 0.2.0（2026-10-17）官方网页登录

加入隔离会话的官方网页登录，并允许系统截图。

## 0.1.0（2026-10-17）首个测试版

原生 Android 签到应用，账号相互隔离，48 项测试通过。
