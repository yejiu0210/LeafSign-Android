## 单测重点

- 执行器 14 项：两账号两游戏记录隔离、更新凭证不能串号、重复身份拒绝、取消后不开始写入、并发触发不重复执行、超时先查状态、无法查询不重发、部分失败不阻断其他项、未绑定不启用、移除绑定 / 取消关注不再执行、中断恢复、仅失败重试、本地日期边界及诊断脱敏。
- 域名边界 5 项：拒绝明文 HTTP、未知域、后缀冒名域、非 443 端口、URL 内用户信息；均在网络请求之前拒绝。
- B 站 10 项：准确权益状态、资格与 UID 类型、非整数 / 未知码、已领取、观看不足、领取成功与延迟经验区分、Cookie 白名单。
- 网易云 / 贴吧 11 项：签名向量、weapi 结构、准确业务码、正数奖励才成功、未知或零奖励不冒充已签到、Cookie 过滤和错误脱敏。
- 森空岛 8 项：独立外部计算的签名向量、多账号角色区服、两游戏不同返回、10001 / 小数码 / 缺字段保守处理、未绑定与已绑定缺角色区别、脱敏。
- 登录票据 5 项：一次性领取、平台隔离、两分钟过期、后一次登录替换前一次待领票据、时钟倒退拒绝领取。以上均是本地测试数据，不是本人登录验证。

## 最短本人验收路径

1. 使用同签名 0.2.0 覆盖安装（保留本地账号；不要先卸载）。账号 → 添加账号 → 选择平台 / 备注 → 官方网页登录并自动导入，在官网完成登录和验证码，必要时点「登录完成，检测账号」，核对官方昵称 / ID。建议先选一个能立即在官网核对的签到对象，执行后到官方确认；这才完成首个平台真实闭环。
2. 分别添加森空岛主账号和分身账号，确保显示不同 ID、正确角色和区服。先每账号只启用一个角色执行，核对另一账号没有被误执行，再逐步启用其余角色与游戏。没有绑定的游戏应显示未绑定。
3. 同一账号尝试再次添加，应被拒绝；给已有账号输入另一个账号的新凭证，应被身份保护拦住，原账号不被覆盖。
4. 在 B 站官方会员中心确认显示“专属等级加速包”，手动完成观看条件后执行。回到官方入口核对已领取；经验流水未确认时只认可领取 / 受理结果，不宣称已到账。
5. 重复点击、离线、请求中断和部分账号失效分别观察。未知必须待确认；恢复网络后查询或重试。不要为测试购买、续费、投币、补签、兑换或绕过验证码。
6. 退出并重开 App，已完成记录保留；中断记录不能变成功。前台真实成功后再按需开启后台，隔日观察实际运行与省电影响。

需要本人补充的最少事项：**在自己手机安装并在 App 本地完成登录凭证导入和上述验收**。不需要把密码、Cookie 或 Token 发到聊天。若出错，可反馈平台、任务、脱敏业务码与已遮盖个人信息的官方入口说明；只有接口确实无法实现而需无障碍时，才需要进一步手机品牌、Android 版本、分身方式及官方 App 版本。
