## 最短新增功能验收

1. 使用同签名 0.4.0 覆盖安装，无需卸载，账号与历史保留。
2. 设置 → 外观切换深色/浅色/跟随系统，重开App确认保存，打开登录页检查原生工具栏可见。
3. 添加小黑盒账号，在官方页面自行登录、验证码自行处理，核对昵称与ID；执行签到后到官方「任务」查看今日签到状态。未知返回应显示待确认，不能假成功。
4. 贴吧旧账号先「校验 / 刷新」，勾选每个需要的吧的随机点赞任务。先启用一个吧执行，按结果中的吧名和帖子ID到官方核对；同日再执行不应取消重赞。再启用第二个吧，验证各自一天一帖。
5. 经验以官方流水/等级记录为准。遇登录失效、手动验证或待确认，更新授权或稍后仅重试失败项，不发送凭证到聊天。

精确业务重置时刻仍需官方证据及跨日确认。本地暂按 UTC+8 零点分日，平台实时查询优先；贴吧点赞是工具的每日限额，完成checkpoint防止本地重复操作，不冒充官方经验任务。
