# 指定小黑盒社区入口

2026-10-17，按用户明确要求将首次打开、重试与账号帮助中的官方入口统一改为 `https://xiaoheihe.cn/app/bbs/home`。应用不主动加载此前的独立登录中心，也不拦截官方正常社区导航。

本次通过桌面 Edge 打开此精确地址，点击页面“登录”，仍在相同地址显示验证码/密码登录、用户协议与隐私政策、二维码；没有输入账号、发送短信、勾选协议或登录。页面没有 viewport meta。保留 WebView 宽视口、overview 与双指缩放，用户自行操作表单与协议。

自动检测只读当前受信页面的五项 Cookie 白名单；不完整时不隐藏页面、不改状态提示、不请求身份。完整一致后才向官方校验并导入；手动检测仍可显示未取得会话的原因。独立单测固定精确启动地址，其他平台入口不变。

这只是公开网页入口检查及实现说明，没有 Android WebView 或真实账号授权成功证据。
